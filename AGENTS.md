# Repository operating instructions

Product-proof-policy: product-proof-loop.v2.1 https://github.com/kwonsyup/Kwon-AI-Workflows/blob/main/policy/product-proof-loop.v2.1.md

Keep the current slice ledger truthful. Do not store message bodies, provider
credentials, raw session identities, SSH targets, transcripts, or device captures in
the repository. Keep local correctness, live proof, and release readiness separate.

Work on an issue branch, preserve one writer per mutable surface, run the repository
checks before integration, and independently read back any public release claim.
